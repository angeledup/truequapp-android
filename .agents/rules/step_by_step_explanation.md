# Antigravity IDE Rule: Explicación Detallada Paso a Paso (Regla 3)

## 📌 Directiva Obligatoria
En este proyecto (`truequapp-android`), **el Asistente/Agente debe explicar a detalle lo que se va a realizar paso a paso antes o durante cada etapa de desarrollo**.

---

## 1. Alcance de la Regla
* Todo plan de acción, módulo a construir, componente UI, caso de uso o prueba debe presentarse de manera estructurada, transparente y pedagógica.
* El usuario debe conocer en todo momento:
  1. Qué paso se está ejecutando y cuál es su objetivo técnico.
  2. Qué archivos y módulos se están creando o enlazando.
  3. Qué reglas de negocio o requisitos se están cubriendo.
  4. Cómo se probará y verificará el resultado obtenido.
